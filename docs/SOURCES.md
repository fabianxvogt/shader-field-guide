# Primary sources

The v1 implementation uses the following official Khronos specifications as the source of truth for the browser shader contract. No external or private data is bundled.

- [WebGL 2.0 Specification](https://registry.khronos.org/webgl/specs/latest/2.0/)
- [OpenGL ES Shading Language 3.20 Specification](https://registry.khronos.org/OpenGL/specs/es/3.2/es_spec_3.2.pdf)
- [GLSL 4.60 Specification](https://registry.khronos.org/OpenGL/specs/gl/GLSLangSpec.4.60.pdf)

The educational wording and reviewed lesson equations are original project content. The app does not claim that the five lessons are a formal shader course or that a browser fallback is equivalent to a GPU driver.
